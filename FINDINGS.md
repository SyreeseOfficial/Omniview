## High value

1. [ ] **[XS]** _Bug_ — `npm start` serves an empty library. After `server.js` was split, `server/store.js` builds its default paths from `__dirname` (the `server/` folder), so `DB_PATH` is `server/db/library.json` and `UPLOADS_DIR` is `server/uploads` (run today: `node -e "require('./server/store')"` prints both), while the real data is in `db/` and `uploads/` at the repo root. Empty `server/db` and `server/uploads` folders were created on 2026-10-18 by starting the server. Use `path.join(__dirname, '..', 'db', ...)` and `'..', 'uploads'`; tests and `npm run demo` hide this because they set the env overrides.
2. [ ] **[XS]** _Privacy_ — The app is not offline-only as the README claims. `public/index.html` loads Inter and Fraunces from `fonts.googleapis.com` (run today: grep shows the Google Fonts `<link>`), so every page load tells Google you opened Omniview, and the typography changes when you are offline. Self-host the two font families as woff2 under `public/fonts/` and drop the external link (as Start-Page already does).
3. [ ] **[XS]** _Security_ — Private data is committed. `db/library.json`, `db/fashion.json` (a personal fashion wishlist with prices) and 61 screenshot files in `uploads/` are tracked, and `.git` is 33 MB. Before the repo is ever pushed or shared, move data out of git (`git rm --cached`, ignore `db/*.json` and `uploads/`) or keep it in a separate private repo; the `changelog` script already filters "library data and uploads" commits, which shows the data commits are routine.
4. [ ] **[S]** _Data_ — Backups lose screenshots. `backupDaily` copies only the library JSON (older item) but trash purge and delete remove image files immediately, so a restored backup shows broken images. Include an `uploads/` manifest (file list + sha256) in each daily backup and keep purged files for the same 7 days in `uploads/.trash/` before deleting.
5. [ ] **[S]** _Data_ — Add the import that export promises (older H item) together with a `version` field in `library.json` and numbered migrations; without a versioned shape the importer will need ad-hoc guessing for every old export.
6. [ ] **[S]** _Quality_ — Add a smoke test that starts the server with **no** env overrides in a temp copy of the repo and asserts `/api/entries` returns the library found in `db/`. Every existing test sets `OMNIVIEW_DB_PATH`, which is exactly why the default-path regression above went unnoticed.
7. [ ] **[?]** _High_ — Import. Export exists (`/api/export`, JSON + ZIP) but there is no way to restore from it. Add `POST /api/import` accepting the ZIP (merge or replace) and a Settings button.
